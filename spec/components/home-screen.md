## 5. 状態（取り方と表示）

**外部の API は呼ばない**（#846）。ローカルの DB・設定ファイル・キーストア・ComfyUI の同梱エンジンの**プロセスの状態**だけを読む。外部の ComfyUI へ接続して確かめることもしない（最大 10 秒かかりうる。接続は各画面で確かめる）。

- **読み込みの仕組み**（決定事項 2(b)）: 各カードの状態の枠が `hx-get="/tools/<ID>/status" hx-trigger="load" hx-target="this" hx-swap="innerHTML"` を持つ。ページの表示は状態を待たない。
- **応答は常に 200**（読めなくても）。本文は `Badge` ＋短い文の断片、または**空**。空なら状態は出ない（カードは出る）。`Cache-Control: no-store`。サーバー側で 2 秒の締め切り（`context.WithTimeout`）を持ち、超えたら空を返す。5xx にしないのは、`main.ts` の失敗のトースト（`htmx:responseError`）がカードの数だけ並ぶのを避けるため。
- 取得は `web/handler/toolstatus/`（新しいパッケージ。`handler/` は基準値 2,895 行で上限を超えている）。サービスは `modelmanager.Service.Engine()`・`workflows.Service.List`・`ReviewService.Inbox`・`CredentialService.Status`・`chatgpt.Service.Overview`（トークンの保存場所の読み取りだけ。ネットワークなし）。organism・molecule はサービスを import しない（`layers_test`）。ハンドラーが表示用の値に直して渡す。

### ComfyUI の状態（ノード・モデルマネージャー）

同梱エンジンの状態（`modelmanager.EngineView`。`Process.State` は `stopped`/`starting`/`running`/`failed`、`Installed`・`Supported`）と、登録済みの外部 ComfyUI の件数（`localmodels` の接続先のうち種類 ComfyUI）から決める。外部は件数のみ。

| 同梱エンジン | 外部 ComfyUI | 表示（`Badge` ・ 文） |
|--------------|-------------|----------------------|
| 起動中（`running`） | — | ok ・ ComfyUI: 起動中 |
| 起動しています（`starting`） | — | info ・ ComfyUI: 起動しています |
| 停止中（導入済み） | — | neutral ・ ComfyUI: 停止中 |
| 起動に失敗（`failed`） | — | error ・ ComfyUI: 起動に失敗 |
| 未導入、または非対応（Windows 以外） | 1 件以上 | neutral ・ 外部の ComfyUI: n 件 |
| 未導入 | なし | **ノード**: warn ・ ComfyUI が必要です ／ **モデルマネージャー**: neutral ・ ComfyUI: 未導入 |
| 非対応（Windows 以外） | なし | **ノード**: warn ・ ComfyUI が必要です ／ **モデルマネージャー**: neutral ・ 同梱の ComfyUI は Windows 版のみ |

- 同梱が導入済みで外部もあるときは、同梱の状態を出す（外部の件数は足さない）。
- 「起動中」は同梱の ComfyUI が動いている状態（Issue の表記どおり）。`starting` は別の文言にして区別する。文言は §9 の質問 3。
- 上の表のうち同梱エンジンの 6 状態は Windows 実機での確認が要る（**未検証**）。非 Windows の「非対応」は Linux 上でも確かめられる。

## 7. アクセシビリティ

| 項目 | 規則 |
|------|------|
| リンクの名前 | タイトルだけ（`aria-labelledby`）。説明と状態は `aria-describedby`（WCAG 2.5.3） |
| キーボード | Tab でカードを上のグループから順に選べ、Enter で開く。カードの中に別のタブ停止は無い |
| フォーカス | `focus-visible` の輪（`indigo-400`、`neutral-950` 上 6.64:1）。ホバーだけで意味を足さない |
| 色だけで伝えない | 状態は `Badge` の**文字**（起動中・停止中・必要です…）で伝える。トーンは補助（#790・#795） |
| コントラスト | 説明 `neutral-400`（`neutral-900` 上 7.11:1）、状態の文 `neutral-300`、CTA・アイコン `indigo-300`（8.99:1）。`text-neutral-500` は使わない |
| 動き | `prefers-reduced-motion` のとき `transition` を切る（`motion-reduce:transition-none`）。アニメーションなし（#797） |
| 見出し | h1 → h2 → h3（#781）。グループの `<ul>` は `aria-labelledby` で見出しに結ぶ |
| 読み込み中 | 状態の枠は `aria-live` にしない。失敗してもトーストを出さない |
